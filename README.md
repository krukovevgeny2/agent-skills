# Навыки

Каталог навыков. Рабочий поток: `skills/agentFlow`. Рядом лежат навыки, без которых он не идёт: `gate`, `grill-me`, `grilling`, `to-tickets`.

## Установка

Скопируйте каталог `skills` целиком в каталог навыков агента. Имена `agentFlow`, `gate`, `grill-me`, `grilling` и `to-tickets` должны находиться. Отдельно их ставить не нужно: `agentFlow` читает соседние файлы по относительному пути.

Определения агентов из каталога навыка не подхватываются, их нужно скопировать отдельно. С ними стартовый контекст ролей намного меньше. Без них поток работает через `general-purpose`, но дороже. Агенты загружаются при старте сессии, поэтому после копирования откройте новую:

```bash
mkdir -p ~/.claude/agents && cp skills/agentFlow/agents/*.md skills/researchFlow/agents/*.md ~/.claude/agents/
```

После этого в чате проекта запустите команду `/agentFlow`. Словами навык не запускается: он скрыт от модели, и без команды агент только прочитает его файлы.

Агент становится диспетчером и ведёт работу по ролям навыка. Правила продукта остаются в том проекте.

## Как устроен поток

Диспетчер говорит с пользователем и запускает четыре роли:

- постановщик закрывает развилки с пользователем и нарезает спеку на задачи;
- кодер пишет код и тесты по одной задаче;
- ревьювер проверяет diff и отвечает «готово», «замечание» или «развилка»;
- поставщик коммитит задачу в её ветку и сливает её в ветку фичи.

Когда все задачи закрыты, ревьювер делает итоговую проверку фичи. Ветка фичи ответвляется от ветки, открытой при запуске потока. В конце диспетчер предлагает слить фичу в эту же ветку и ждёт явного подтверждения. Пользователь может назвать другую ветку.

Ветки ведёт скрипт `skills/agentFlow/worktree.sh`: шаг `sync` вливает кончик ветки фичи в ветку задачи, шаг `record` коммитит журнал и правки правил. Шаг `tokens` считает реальный расход токенов по агентам, задачам и диспетчеру из транскриптов Claude Code и пишет отчёт в `.agentflow/.scratch/<feature-slug>/tokens.md`; `merge` запускает его сам. Нужен Perl, цены лежат в таблице в начале `skills/agentFlow/tokens.pl`.

При старте шлюз проверяет git, соседние навыки и каталог `.agentflow/docs/adr/`. Он добавляет строку `.agentflow/.worktree/` в `.gitignore`, а строку `.agentflow/.scratch/` в `.git/info/exclude`. Общие правила лежат в [skills/agentFlow/roles.md](skills/agentFlow/roles.md), правила каждой роли в каталоге [skills/agentFlow/roles/](skills/agentFlow/roles/).

## Исследование

`skills/researchFlow` разбирает баг, MR или новую фичу и выбирает лучший вариант. Запуск командой `/researchFlow`. Ему нужны соседние `grill-me` и `grilling`.

Диспетчер говорит с пользователем и ведёт пять ролей:

- постановщик опрашивает пользователя, пишет спеку с критериями и бюджетом, проверяет гипотезы автора и пишет к каждой план опыта с предсказанием;
- автор гипотез выдаёт гипотезы пачками и разбирает новые идеи;
- проверяющий ставит опыт по одной гипотезе в своём worktree, не больше трёх одновременно;
- критик проверяет спеку, каждый вердикт вместе с планом и отчёт;
- сравнивающий оценивает гипотезы по критериям спеки и пишет отчёт.

Итог лежит в `.agentflow/docs/research/<slug>/`: `report.md` с решением и ссылками, файлы гипотез и журналы опытов. Каталог коммитится в текущую ветку, код опытов удаляется. Запреты держит `skills/researchFlow/research.sh`: без предсказания опыт не начнётся, без вердикта, нетронутого журнала и приёмки критика гипотеза не закроется, без всех ссылок отчёт не пройдёт. Приёмку записывает шаг `accept` по слову критика, правка объекта после неё приёмку снимает. Шаг `tick` сам заводит опыты на свободные слоты, выполняет подготовку из спеки и печатает диспетчеру, что делать дальше; по нему же исследование продолжается после перерыва. Бюджет считается с начала исследования. Модели ролей задаёт таблица в `skills/researchFlow/SKILL.md`.

Пробный прогон на игрушечном баге: скрипт заводит репозиторий, затем в новой сессии в этом каталоге запустите `/researchFlow`.

```bash
bash scripts/research-demo.sh ~/tmp/research-demo
```

## Проверка

Проверка ссылок, frontmatter и плейсхолдеров в навыках. Зависимостей нет, нужен Node.js:

```bash
node scripts/check-skills.mjs
```

Сценарии `research.sh` и цепочки шага `tick` на временном репозитории, без агентов. Нужны bash, git и Perl:

```bash
bash scripts/research-test.sh
```
