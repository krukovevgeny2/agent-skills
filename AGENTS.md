# Навыки

Этот репозиторий хранит навыки. Продуктовый код здесь один: страница `agentflow.html`. Файлы навыков в `skills/` меняются только по прямой просьбе пользователя.

Навык agentFlow лежит в `skills/agentFlow`, навык исследования researchFlow в `skills/researchFlow`. Рядом `skills/gate`, `skills/grill-me`, `skills/grilling` и `skills/to-tickets`. Правила потока не копировать в этот файл.
